# 🌾 PestRisk AI

Rice pest risk prediction and sustainable IPM advisory system.

## Architecture

Weather + Time + Location + Pest
        ↓
ML Risk Prediction
        ↓
Predicted Observation Risk
        ↓
RAG Knowledge Retrieval
        ↓
Evidence-Grounded Advisory
        ↓
Farmer-Facing Dashboard

## Project Structure

- app.py — Streamlit application
- models/ — ML model artifacts
- rag/ — RAG retrieval components
- data/ — supporting data
- assets/ — UI assets
- logs/ — application logs
